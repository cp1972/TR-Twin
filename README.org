#+TITLE: Theory of the Relation — Simulator (Digital Twin)
#+OPTIONS: toc:nil num:nil ^:nil
#+LANGUAGE: en

A stand-alone web application (HTML/JavaScript, Canvas graphics) that simulates the *Theory of the Relation*. It represents four mutually influencing relational structures — *Culture (A), Politics (B), Economy (C), Media (D)* — each articulated into sequences and into four actor categories, and it lets you feed in real data to observe the mutual influence of social orders, the unequal circulation of actors, and the social inequalities that arise from it.

*Theoretical basis:* Christian Papilloud & Eva-Maria Schultze, /Skizze einer Theorie der Relation/, Springer VS, Wiesbaden 2022 (ISBN 978-3-658-37922-3).

* Run it

The simulator is a single, self-contained file: =index.html=.

- *Locally:* download or clone the repository and open =index.html= in any modern web browser. No build step, no server, no dependencies.
- *Online (GitHub Pages):* enable Pages in the repository settings (Settings → Pages → deploy from branch, root =/=); the simulator is then served at =https://<user>.github.io/<repository>/=.

The interface switches between *English, German, and French* (the DE·EN·FR pill at the top right; English by default).

* What it does

The simulator pursues three purposes: (1) it tests the coherence of the Theory of the Relation by proposing a runnable simulation of it; (2) it lets you model the relational schemes of other variants of relational sociology, to make the contrasts visible; (3) it lets you model real datasets, to see which configurations of the relational orders the data bring to light and to track them over time. It accepts real demographics, time-varying controller profiles ("theory profiles"), and real actor cohorts as CSV, and it exports deterministic result outputs (CSV time series, actor transitions, and print-ready SVG figures).

* Reproducibility

A random seed fixes the small initial perturbation; the same seed and the same settings yield the same trajectory. This makes the simulator a comparative analysis tool. All mechanisms were first calibrated and verified headless (Node.js) before being taken into the application; the perfect, symmetric state (equally large structures, reciprocity ~1, inequality 0) is preserved by every mechanism.
