#+TITLE: Worked example — English working-class authors and their instances
#+OPTIONS: toc:nil num:nil ^:nil
#+LANGUAGE: en

This example runs the digital twin on a cohort of *163 English working-class autobiographers*
(the art-and-media subset) and on the *mediation and control instances* they passed through —
schools and universities, literary reviews and societies, newspapers and news agencies. It
reproduces the project's main finding and its deepening.

* The finding (and its deepening)

*Main finding.* These authors are *atypical by destination* — they cross into other relational
structures, above all *Culture (A)* and *Media (D)* — yet *typical* once one remembers how few
workers had such a fate.

*Deepening (this example).* What carried that atypical crossing? The *instances*. The workers do
not cross into a vacuum: they enter through the mediations, and above all through the *control
instances* that sort, certify and consecrate (certification and criticism in A; gatekeeping and
economic evaluation in D). Over time, the working-class presence in A and D builds up in lockstep
with those instances (corr. presence–control 0.78 in A, 0.98 in D; presence–mediation 0.81 in A,
0.63 in D). See =figures/course_transversal.svg= and =provenance/course_transversal_notes.md=.

*Caveat (book chapter 12).* These correlations use the estimated years of the contract table and
link two series that both grow over the century. With the years taken from the notices and on
ten-year changes (the common trend removed), the coupling holds clearly only for mediation in A
(0.56); the stratification of the economy (C) is robust, the homogeneity of politics (B) depends on
how political offices are placed on the HISCAM scale. The cross-check with topic models, the
re-dated contract tables and all scripts are in [[file:topic-models/README.org][topic-models/]].

* Run it in the twin (the "course" configuration)

Since v68 the run is prepared in a run file: =runs/worked_example.csv= names the two tables.

1. Open =tr-twin.html= (at the repository root) in a browser.
2. /Choose run file and data…/ → select =runs/worked_example.csv= together with
   =data/actors/cohorte_contrat.csv= (the actor cohort: it drives the field — actor circulation,
   structure sizes, inequality, reciprocity) and =data/instances/instances_full_empirical.csv=
   (the *mediation* instances, which drive the sequences, and the *control* instances, rows with
   =categorie = controle=, routed to control capacity).
3. /▶ Compute/: the results open (trends per decade, detail per structure, circulation and
   mobility, permeability, figures). Close them and press /▶ Start/ to watch, together: the actors
   circulating across structures, the instances waxing and waning, the control capacity of A and D
   building up, and reciprocity declining as the destinations fill.
4. The same from a terminal: =node run.js runs/worked_example.csv= (see
   [[file:../techdocs/04-headless-runs.org][document 4]]).
5. Optional: the key =categories= sets what the twin uses in years in which a structure has no
   active actor — =uniform= 25 % per category (default, as up to v63), =composition= (the overall
   composition of the structure), or =carry= (the last observation carried forward). Here A is
   empty in 47 of 209 years, B in 129, C in 23, D in 81. See [[file:topic-models/README.org][topic-models/]] for why this matters.

* The data (=data/=)

- =actors/cohorte_contrat.csv= — the 163 authors as a contract table (aid, year, structure,
  category, sequence).
- =instances/instances_full_empirical.csv= — *the file to load*: mediation + control instances.
- =instances/instances_extract_contract.csv= — the raw catalogue of 60 instances extracted from
  the autobiographies (the source for the two below).
- =instances/control_parc_empirical.csv= — the control instances only (empirical labelling).
- =instances/instances_probe_demo.csv= — six milestone-anchored mediation probes.
- =instances/instances_cohort_demo.csv=, =control_parc_demo.csv=, =probes_extract_demo.csv= —
  illustrative/demo tables (generic weights) used by the documentation figures.

* The figures (=figures/=)

- =instances_lifelines.svg= — birth → force (weight) → death of the mediation instances.
- =signals_comparison.svg= — four signals (circulation, instance force, inequality, reciprocity)
  per structure and overall.
- =control_capacity_empirical.svg= / =control_profile_empirical.svg= — the control apparatus of the
  cohort: capacity by structure, and the differential by sequence.
- =control_capacity.svg= / =control_profile.svg= — the same on the illustrative demo parc.
- =course_transversal.svg= — *the deepening figure*: working-class presence in A and D vs the
  mediation and control instances that channel the crossing.

* Provenance (=provenance/=)

- =control_parc_empirical_notes.md= — instance-by-instance labelling of the control parc (structure,
  target sequence, weight) and the empirical finding (A's control apparatus exceeds D's, as expected
  for an emerging media sphere).
- =instances_probe_demo_notes.md= — sources for the six milestone-anchored probes.
- =course_transversal_notes.md= — the deepening result and its correlations.

* Reproduce the figures (optional)

Run from the *repository root*. The pipeline is: a Node harness replays the twin headless and
writes a JSON to =/tmp=; a Python generator turns it into an SVG.

#+begin_src sh
# control-apparatus figures (no replay needed)
python3 data-mode/scripts/figures/gen_control_capacity.py light \
  data-mode/figures/control_capacity_empirical.svg \
  data-mode/data/instances/control_parc_empirical.csv 1950
python3 data-mode/scripts/figures/gen_control_profile.py  light \
  data-mode/figures/control_profile_empirical.svg \
  data-mode/data/instances/control_parc_empirical.csv 1950

# the deepening figure (replay → JSON → SVG)
node   data-mode/scripts/runs/course_analysis.js  # writes data-mode/data/derived/course.json
python3 data-mode/scripts/figures/gen_course.py light \
  data-mode/figures/course_transversal.svg

# four-signals comparison (replay → JSON → SVG)
node   data-mode/scripts/runs/replay_signals.js   # writes data-mode/data/derived/signals.json
python3 data-mode/scripts/figures/gen_compare.py light \
  data-mode/figures/signals_comparison.svg
#+end_src

The headless harness needs Node.js with =jsdom=; the generators need Python 3 (=cairosvg= only if
you also want PNGs).
