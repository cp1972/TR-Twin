#+TITLE: Simulation mode — contrasting theoretical frameworks
#+OPTIONS: toc:nil num:nil ^:nil
#+LANGUAGE: en

In this mode nothing empirical is loaded. A *cursor profile* encodes how a
theoretical framework construes circulation, mediation, reciprocity and
satellisation; the twin then runs that framework and you watch what it
produces. Held against the TR's own reference state, the difference is the
framework's signature.

* Run a profile

Since v68 a comparison is prepared in a run file that names the profiles (=runs/compare_parsons_luhmann.csv=,
=runs/vergleich_theorien.csv=); the TR is always computed as the reference.

1. Open =tr-twin.html= (repository root) in a browser.
2. /Choose run file and data…/ → select the run file together with the profiles it names.
3. /▶ Compute/: the assumptions of the theories next to the TR, the results over the seeds with the
   difference to the TR, the changes of regime and the figures. /▶ Start/ replays one run.
4. The same from a terminal: =node run.js runs/compare_parsons_luhmann.csv=.

* The profiles (=profiles/=)

Twenty-four profiles covering Parsons (plus a damped variant), Luhmann,
Habermas (ideal and two colonisation variants), White (with interface, arena,
council and four hub variants), Tilly, Bourdieu (dialectical and
non-dialectical), the two intersectionality readings, Emirbayer, Donati,
Archer, Dépelteau and Fuhse/Mische.

* Headless runs (=scripts/runs/=)

Node.js with =jsdom=. Run from the repository root.

#+begin_src sh
node simulation-mode/scripts/runs/run.js tr-twin.html \
     simulation-mode/profiles/profil_Parsons.csv

node simulation-mode/scripts/runs/batch.js      # all profiles, 1819 steps
node simulation-mode/scripts/runs/sweep.js      # parameter sweep
node simulation-mode/scripts/runs/metrics.js tr-twin.html \
     simulation-mode/scenarios/spec_white.json
#+end_src

- =run.js= / =run_steps.js= — a single run, free or with fixed cursors
- =batch.js= — every profile in step mode
- =sweep.js= / =search.js= — parameter sweep and targeted search
- =hysteresis.js= — run a phase, then continue without reset
- =metrics.js= — end-state metrics for a set of configurations
- =archer_zyklus.js= — the three runs of the Archer cycle (book ch. 9, fig. 3), Gini at steps 0, 1250, 2500, 3750, 5000

See [[file:../techdocs/04-headless-runs.org][techdocs/04]] for the details.

* Figures (=scripts/figures/=)

- =render_trajektorie.py= — the trajectory and end-state figures
- =render_schema.py= — the schematic diagrams
- =render_archer.py= — redraws the Archer figure from the output of =archer_zyklus.js=
- =rework_figures.py= — a *one-off* pass that brought the existing SVGs to the
  present typographic standard (larger type, legend at mid-right, no title in
  the image). It is *not* idempotent: running it twice enlarges the type twice.
  It is kept for provenance, not for routine use. Applied once to a freshly
  rendered trajectory it gives the present style (as for the Parsons figure,
  regenerated with tr-twin.html v63: =run_steps.js= → =render_trajektorie.py= →
  =rework_figures.py=, decimal comma in the labels).
